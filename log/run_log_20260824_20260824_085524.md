若总净买入为负（龙虎榜整体净卖出），则标注「总净卖出，机构逆势净买入」，代表当日其他席位以卖出为主，机构资金独立逆势加仓。

一、市场全景：缩量分化，资源与算力双线并行
8月21日，A股三大指数窄幅震荡收涨。上证指数微涨0.04%收于3905.20点，深证成指上涨0.87%报14094.17点，创业板指上涨1.43%报3545.58点，科创50微涨0.04%报1653.56点，北证50下跌0.57%。两市成交额1.88万亿元，较昨日缩量约2000亿元，上涨2505家、下跌2862家，涨停58家（较昨日83家回落）、跌停15家——市场在超跌反弹后进入缩量分化阶段，短线情绪较昨日降温。
今日盘面呈现"资源双雄+算力链"三线并行的格局。资源端，贵金属与锂矿集体爆发——美国财长贝森特释放国债回购规模或超上限的信号，美债收益率应声下跌，现货黄金涨至4530-4543美元/盎司创6月以来新高（盘中一度突破4600美元），白银逼近69美元；湖南白银、盛达资源、白银有色涨停，贵金属板块主力净流入24.77亿元。锂矿方面，广期所碳酸锂主力合约站上15.5万元/吨（8月以来涨幅超17%），中信建投预计Q4供需缺口达峰值，融捷股份、*ST威领涨停，锂矿板块主力净流入33.46亿元。算力链方面，SK海力士表态"CPO是系统级HBM创新规模化的关键"，叠加新易盛推出股权激励计划（授予价212元/股），光通信/CPO板块主力净流入91.84亿元居全市场之首，通鼎互联2连板、星网锐捷/瑞斯康达涨停，"易中天"三巨头成交额合计616亿元。
与此形成对照的是三个方向的退潮。第一是医药生物——昨日30+涨停的爆发今日大幅分化，CRO/创新药领跌（哈药股份、美诺华、哈三联跌停），生物疫苗回调（华兰疫苗、安科生物跌超11%），仅汉森制药3连板、键凯科技/康希诺/近岸蛋白/贝瑞基因2连板维持晋级，完全印证"医药首日爆发、次日分化"的规律。第二是农业/粮食——事件兑现后崩塌，秋乐种业跌超15%、神农种业跌11%、京粮控股/万向德农/红四方跌停，摩根大通粮食危机逻辑在3连板后彻底证伪。第三是高位人气股——一鸣食品、红四方、开开实业、百合花跌停，宇树科技午后转跌（收672.41元，较开盘1100元回撤近40%），高位股监管收紧的威慑持续发酵。
二、P0：贵金属/黄金——金价创6月新高，避险进攻双轮驱动（建议关注15%）
贵金属板块今日以+4.64%的涨幅领涨全市场，湖南白银涨停（+10.03%）、盛达资源涨停（+10.01%）、白银有色涨停（超61万手买单封板），赤峰黄金涨超6%、晓程科技涨超7%，板块主力净流入24.77亿元。
核心催化是美债收益率的再度下行。8月20日晚美国财长贝森特表示，国债回购单次规模上限可能超过已宣布的40亿美元，并强调"可以通过自身发展摆脱债务负担"——受此消息影响，美债收益率应声下跌，国际金价重新站上4500美元并进一步攀升至4530-4543美元/盎司（盘中突破4600美元），现货白银涨超1%逼近69美元/盎司。叠加此前30年期美债收益率从5.32%的2007年高点回落、美元指数走弱、去美元化趋势下的央行购金持续，黄金的"避险+进攻"双重逻辑进一步强化。
与前两日的区别在于，今日贵金属的强势从"紫金矿业等权重驱动"扩散为"白银/小金属全面开花"——湖南白银、盛达资源、白银有色等弹性标的涨停潮，说明资金对该方向的参与从"被动配置"升级为"主动进攻"。白银的弹性（金银比修复+工业需求）成为板块内部最强的细分方向。短期需注意金价急涨后的技术性回调风险，但中期看，美债利率回落+地缘冲突+央行购金三重逻辑未破坏，回调即布局的节奏不变。
三、P1：锂矿/能源金属——碳酸锂站上15.5万，供需缺口逻辑强化（建议关注10%）
锂矿板块今日大涨4.60%领涨市场，融捷股份、*ST威领涨停，盛新锂能、永杉锂业涨超6%，赣锋锂业涨超5%、天齐锂业涨超4%，板块主力净流入33.46亿元。
核心催化是碳酸锂价格的持续上行。广期所碳酸锂主力合约LC2609早盘涨幅超2.5%站上15.5万元/吨，8月以来从月初最低13.43万元/吨一路攀升，至8月17日盘中最高触及15.75万元/吨，累计涨幅超过17%。中信建投最新研报认为，随着下半年需求旺季到来，碳酸锂供需缺口将逐步放大，四季度达到缺口峰值，若考虑产业链提前备货，年内价格高点可能出现在三季度末至四季度初。北方稀土同日披露中报——上半年营收257.99亿元（+36.75%）、归母净利20.53亿元（+120.46%），资源板块业绩兑现进一步强化涨价逻辑。
锂矿的崛起延续了"资源涨价"的主线脉络：从8/5的有色小金属、8/6的黄金4300美元、8/19的焦炭提涨，到今日的锂矿+贵金属双雄——资源板块内部呈现"轮动扩散"的特征，资金在贵金属、锂、稀土、焦炭等细分间循环。但需注意，锂矿属于典型的"价格驱动"行情，碳酸锂期货走势是核心变量，15.5万元/吨上方若出现期货回调，板块将同步调整；当前以"涨价趋势未破坏"为前提跟踪参与。
四、P1：光通信/CPO——SK海力士定调+新易盛激励，算力链资金回流（建议关注10%）
光通信/CPO板块今日主力净流入91.84亿元居全市场之首，通信设备板块上涨2.98%、净流入8.89亿元，是今日最强的资金进攻方向。
两大催化叠加。产业层面，SK海力士表态"CPO是系统级HBM创新规模化的关键"，随着客户构建更大规模的AI系统，光互连的重要性与日俱增——这为CPO提供了与HBM同级别的产业背书，是继英伟达CPO交换机量产之后最重磅的产业确认。公司层面，新易盛发布2026年限制性股票激励计划（拟授予648.12万股，授予价212元/股），股价大涨近7%市值突破6100亿元，"易中天"三巨头成交额合计616亿元；中际旭创今晚发布财报，市场对业绩预期积极。
涨停梯队：通鼎互联2连板（光纤预制棒全产业链，上半年扣非净利猛增超3856%）、星网锐捷涨停（+10.02%）、瑞斯康达涨停、天洋新材涨停，光通信方向的超跌反弹延续昨日太辰光/通鼎的强势并扩散至设备/材料环节。光通信在本轮"暴跌-反弹"周期中表现出最强的修复弹性（8/20太辰光+18.38%、8/21板块净流入91.84亿），核心逻辑是AI算力资本开支的确定性——只要北美云厂资本开支与英伟达产业链预期不塌，光通信就是科技方向最值得跟踪的主线。风险在于"易中天"等老龙头前期套牢盘沉重（20日净流入仍为-237.67亿），反弹高度受制于筹码结构，参与以低吸新晋龙头为主。
五、P2：液冷服务器 + MLCC——AI产业链新扩散方向（建议关注6%+5%）
液冷服务器概念今日活跃，飞龙股份、金富科技涨停，大元泵业、冰轮环境、川环科技跟涨。催化是华源证券研报指出，英伟达下一代800HVDC架构CDU拟采用高压直流电子屏蔽泵，谷歌2MW CDU方案确认可采用，测算2027年单谷歌需求对应泵市场超25亿元——液冷作为AI算力密度提升的必然配套，开始获得产业链级关注。
MLCC概念走强，国瓷材料涨超7%、斯迪克、火炬电子跟涨。催化是MLCC价格持续上涨——截至2026年8月，普通标准品现货价格上涨超20%，AI服务器用10μF、20μF等高容产品平均涨幅达60%-80%，部分特殊型号价格直接翻倍；三星电机Q2财报显示元器件事业部营收1.6494万亿韩元（+29%）、营业利润同比暴涨106.7%。MLCC涨价逻辑与8/5-8/6的电子化学品/半导体材料涨价一脉相承，是AI算力向被动元件传导的又一确认。
两个方向均为"AI产业链的扩散补涨"，弹性大但持续性依赖主线的延续。液冷看英伟达产业链订单落地节奏，MLCC看涨价函覆盖广度——当前均属"跟踪观察、轻仓参与"级别。
六、P3回避与风险提示
今日P3回避方向明确：高位粮食股（京粮控股、万向德农、红四方跌停，秋乐种业跌超15%——摩根大通粮食危机"事件兑现"彻底证伪，红四方从3连板一字直接跌停验证"高位分歧即崩塌"）；高位人气股（一鸣食品、开开实业、百合花跌停，监管收紧+情绪退潮双击）；昨日医药爆发后的一字板高位股（哈三联、哈药股份、美诺华跌停，医药首日涨停潮次日分化是最典型的兑现陷阱）。
风险提示聚焦四点：其一，缩量分化——成交1.88万亿较昨日缩量2000亿，涨停58家回落，反弹进入验证期，若明日继续缩量则反弹动能衰减；其二，医药高位分化——昨日30+涨停今日CRO/创新药跌停潮，印证"首日爆发次日分化"，20cm一字板追高风险极大；其三，宇树科技高位回撤——较开盘价回撤近40%，机器人板块情绪标杆走弱，高位题材系统性风险仍在释放；其四，中报密集披露——新易盛今晚财报、中际旭创财报在即，业绩不及预期的高位算力股存在补跌风险。
七、结论摘要
8月21日，A股缩量分化（1.88万亿，涨停58家回落），资源与算力双线并行。贵金属（金价4530-4543美元创6月新高，美债收益率下跌催化）与锂矿（碳酸锂站上15.5万，Q4缺口峰值预期）领涨，光通信/CPO（SK海力士CPO定调+新易盛激励，主力净流入91.84亿全市场第一）强势回流；医药生物昨日爆发后大幅分化（CRO/创新药跌停潮，仅龙头晋级），农业/粮食事件兑现崩塌（京粮/万向德农/红四方跌停），高位人气股持续杀跌。策略建议：P0贵金属（15%），P1锂矿（10%）+光通信/CPO（10%），P2液冷（6%）+MLCC（5%）+医药晋级龙头（4%），回避高位粮食/高位人气股/医药一字板高位；现金升至50%，缩量分化期等待放量方向选择。
